# Password Validator 🔐

## Description
This is a simple Python program that checks whether a password meets specific requirements.

## Requirements
The password must:
- Be at least 8 characters long.
- Contain exactly one uppercase letter.
- Contain exactly one symbol.
- Not contain any spaces.

## Example

**Input:**
```text
enter a password: Abcdefg!
```

**Output:**
```text
valid password
```

## Technologies Used
- Python
